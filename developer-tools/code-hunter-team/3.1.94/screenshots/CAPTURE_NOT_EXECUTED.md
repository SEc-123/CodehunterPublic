# IDE screenshot capture boundary

The VS Code and JetBrains native IDE surfaces were not available to Computer Use in this release environment. The historical images that were present in the private validation archive were intentionally excluded from the public 3.1.94 package because they are not current-version plugin captures.

The current package still has four-platform binaries, VSIX/JetBrains structure checks, and protocol tests. Capture the actual VS Code and JetBrains windows in a native desktop session before adding public screenshot files.
