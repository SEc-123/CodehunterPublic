# Get Started

## Choose an edition

### Personal

Use Personal when one person imports a local project, runs an audit, reviews findings, and prepares reports or a scoped fix package.

[Open Personal](personal/personal-get-started.md)

### Team

Use Team when a workspace, members, code sources, baselines, iterations, SCA, release gates, remediation owners, or IDE agents are involved.

[Open Team](team/team-get-started.md)

## Shared setup

Provider and license settings are available in both editions. The available actions and permissions depend on the edition that is running.

[Configure a provider or license](common-provider-and-license.md)

## Use this guide

Each feature page contains:

1. What the feature does.
2. Where to open it.
3. What to enter or select.
4. What you should see after saving or running it.
5. A product screenshot when one is available.
6. The most common issue and its fix.
