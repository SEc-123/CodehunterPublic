# Personal: Provider

Use this page to save and test the model service used by Personal audits and review actions.

## Configure a provider

1. Open **Settings → Providers**.
2. Select a provider preset.
3. Enter the Base URL.
4. Enter the model name.
5. Enter the API key in the provider form.
6. Select **Save**.
7. Select **Test provider**.
8. Set the provider as default after a successful test.

![Personal provider configuration](../assets/personal/personal-provider.png)

### Result

The provider is listed as saved and can be used by the Personal audit workflow.

### Common issues

- Check the Base URL when the connection cannot be reached.
- Check the model name when the provider returns a model error.
- Replace the API key when authentication fails.
