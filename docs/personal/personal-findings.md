# Personal: Findings and Evidence

Use the Findings workbench to inspect, confirm, and classify audit results.

## Review a finding

1. Open **Findings & Actions**.
2. Select a finding.
3. Check severity and confidence.
4. Read the affected behavior and source location.
5. Open **Proof / Evidence** and follow the evidence chain.
6. Choose one action: **Accept**, **Reject**, **Downgrade**, or **Defer**.
7. Save the decision.

![Personal findings workbench](../assets/personal/personal-findings.png)

### Result

The finding shows its decision, evidence, and current status. Only findings selected for output continue to reporting or remediation.

### Common issue

If the evidence is incomplete, keep the finding unconfirmed, check the project scope and provider result, and run the relevant analysis again.
