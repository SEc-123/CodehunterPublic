# Team: Workspace and Roles

Use the workspace controls to add members and define ownership for review and remediation.

## Add members and roles

1. Open the Team workspace.
2. Open **Members**.
3. Add a member and save the account details.
4. Assign the appropriate role: Security Reviewer, Project Owner, Developer, or Remediation Owner.
5. Save the membership.
6. Assign project ownership where required.

### Result

The member appears with an active role and can receive the projects, findings, or remediation tasks assigned to that role.

### Common issue

If a task cannot be assigned, check that the member is active and has a role allowed for that project.
