# Team: Analysis and Findings

Use the Team analysis workbench to combine requirements, code changes, external reports, and normalized findings.

## Run analysis

1. Open the iteration.
2. Run requirement extraction.
3. Run impact analysis and security analysis.
4. Review control owner and gate policy inputs.
5. Import an external SAST or SARIF report when one is available.
6. Preview the project, branch, commit, scanner, and report date before importing.
7. Run external report analysis.
8. Open the normalized findings.
9. Review change impact, delta generic risk, delta business risk, and delta finding review.
10. Assign each accepted finding to an Owner.

![Team analysis and external findings](../assets/team/team-analysis-and-findings.png)

### Result

The iteration shows normalized findings tied to source, evidence, project impact, and an owner.

### Common issue

If an external report is empty, check the report format, project binding, commit, and report date before importing again.
