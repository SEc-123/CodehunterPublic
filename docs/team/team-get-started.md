# Team: Get Started

Team adds workspace governance, project ownership, shared code sources, analysis stages, SCA, release gates, remediation tasks, and developer collaboration.

## Download and open Team

1. Download Team from the [official Code Hunter download center](https://www.arvantacyber.com/code-hunter/download/).
2. Install and start the Team desktop app.
3. Open **Settings → License** and complete Team activation.
4. Open the workspace selector.
5. Create or select the Team workspace.
6. Confirm that the workspace is available to your account.

![Team workspace entry](../assets/team/team-get-started.png)

### Result

The Team dashboard opens with the selected workspace and its available projects.

### Common issue

If the workspace is not listed, refresh the license and workspace state, then confirm that the account has been added to the workspace.
